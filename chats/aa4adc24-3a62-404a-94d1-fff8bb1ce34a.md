`dotenv` 是一个 Node.js 库，用来把 `.env` 文件里的配置项加载到 `process.env` 中。

**主要用途：**

- 把环境相关的配置（比如数据库密码、API密钥、端口号等）从代码里抽出来，放到一个 `.env` 文件中管理
- 避免敏感信息硬编码到源码里
- 方便不同环境（开发/测试/生产）切换配置

**典型用法：**

```bash
# .env 文件
DB_HOST=localhost
DB_USER=admin
DB_PASS=123456
```

```javascript
// 项目入口的最顶部引入
require('dotenv').config();

console.log(process.env.DB_HOST); // 输出: localhost
```

**配合 `.gitignore` 使用：**

把 `.env` 加到忽略列表，防止敏感配置被提交到代码仓库。仓库里只保留 `.env.example`（示例文件，不含真实密钥）给团队成员参考。

**同类工具：**

- Node.js 原生的 `--env-file` 参数（Node 20.6+）
- Python 的 `python-dotenv`
- 各框架也基本都有类似机制，比如 Next.js 内置支持 `.env.local`

简单说，它就是帮你管理"不该写在代码里、但程序又需要"的那类配置信息。
