## 一、整体定位

这是一个 **CoT（Chain-of-Thought，思维链）对比实验**，目标是验证两件事：
1. 是否有"名词召回 + 拓扑链预筛选"——对最终推理质量的影响
2. DeepSeek 开启 DeepThink（reasoning_effort='high'）后效果如何

实验分两组：
- **实验组一（CoT 直推）**：用纯文表的全部 chunk（不筛选）+ 开启 CoT
- **实验组二（主流程）**：用拓扑链筛选后的少量高相关 chunk + 关闭 CoT（复用根目录已有结果）

## 实验背景

DeepSeek API 的 **prefix cache** 命中规则：从 prompt 开头算起的连续相同前缀才命中。缓存前缀越长、用得越久，省钱效果越好。

原 `multipath-prompt-cot-<id>.txt` 的结构：

```
┌──────────────────────────────────┐ ← 问题头（每个问题不同）
│ PROMPT 1 (Z1-Q1)                 │
│ 问题：Pierre Janet 和 Freud...    │
│ 要求：...                        │
│ 格式：...                        │
│ 引用规范：...                    │
│ 推理策略：...                    │
└──────────────────────────────────┘
┌──────────────────────────────────┐ ← 【【全量材料】】（1446 chunks）
│ ...约 165k tokens 的相同前缀...  │
└──────────────────────────────────┘
```

由于每条 prompt 的"问题头"在 prompt 最前面，**第 2 条到第 15 条 prompt 的 165k tokens chunks 前缀在 API 看来都不算"前缀"**——因为前面拼了不同的 580 字左右问题头。整个批量 15 条的 prefix cache 命中率只有 0%（除了第 2 条偶然复用第 1 条的部分，原因见后）。

## 优化方案

把 chunks 部分挪到 prompt 最前面，问题头扔到末尾：

```
┌──────────────────────────────────┐ ← 【【全量材料】】（1446 chunks）
│ ...约 165k tokens 的相同前缀...  │
└──────────────────────────────────┘

- `header` = `src[0:idx]`
- `chunks` = `src[idx:]`
- `out`   = `chunks + header`

### **方案A：离线预建索引（最彻底）**

// 离线阶段（一次性，可能花几小时）
// 为 16,244 个名词 × 每个名词，预计算其"相关主题"
const nounTopicIndex = {
  "freud": ["无意识", "精神分析", "心理学", "梦", "本我", ...],
  "pierre_janet": ["歇斯底里", "解离", "创伤", ...],
  "inconscient": ["无意识", "潜意识", "意识", ...],
  // ... 16,244 个名词
};

// 在线阶段（用户问问题时）
function quickRecall(question) {
  // 1. 提取问题关键词（本地，0成本）
  const keywords = extractKeywords(question); 
  // → ["freud", "无意识", "心理学"]
  
  // 2. 查表匹配（本地，0成本）
  const candidateNouns = [];
  for (const noun of allNouns) {
    const topics = nounTopicIndex[noun.id];
    const overlap = keywords.filter(k => topics.includes(k)).length;
    if (overlap > 0) {
      candidateNouns.push({ noun, relevance: overlap });
    }
  }
  
  // 3. 精打分（只需几千 tokens，10秒）
  const scored = await scoreCandidates(question, candidateNouns);
  
  // 4. 拓扑召回 → 推理
  return await reasoning(scored);
}
```
